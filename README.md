## BrianAir Database
I made this with my Labbpartner from University

A MariaDB database project for a fictional airline called BrianAir.
The project focuses on designing and implementing a relational database for managing flights, reservations, passengers, and payments.

## Features

- Flight routes and schedules

- Passenger and reservation management

- Dynamic flight pricing

- Payment and ticket handling

- Stored procedures and SQL functions

- Database triggers and views

- Transaction and concurrency handling
